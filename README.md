# Smart Retail AI - Akıllı Yerel Market Yönetim Platformu

Smart Retail AI, yerel marketler ve perakende işletmeleri için akıllı stok, sipariş, tedarikçi ve finansal optimizasyon çözümleri sunan modern bir yönetim platformudur.

## Özellikler
- **Akıllı Satın Alma ve Stok Yönetimi**
- **Tedarikçi Değerlendirme ve Performans Takibi**
- **Finansal Yük Analizi ve Kampanya Yönetimi**
- **Yönetici Özeti & KPI Raporlama**
- **FastAPI Tabanlı Yüksek Performanslı REST API**

## Başlangıç

### Gereksinimler
- Python 3.10+

### Kurulum
```bash
python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### Çalıştırma
```bash
python run_server.py
```
API Dokümantasyonu: `http://127.0.0.1:8000/docs`
